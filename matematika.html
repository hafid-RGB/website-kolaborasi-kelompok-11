Hafid Fatahusna Jatmiko

X PPLG 4 / 17

1. Menentukan Variabel

x = harga satuan 1 smart waste.

y = harga satuan 1 kipas angin smart.

2. Membuat Model Matematika

Paket 1: 6x + 5y = 1.815.000
Paket 2: 4x + 7y = 1.485.000

3. Penyelesaian

6x + 5y = 1.815.000 | ×7
4x + 7y = 1.485.000 | ×5

42x + 35y = 12.705.000
20x + 35y = 7.425.000
_________________ -
22x + 0y = 5.280.000
x = 5.280.000/22
x = 240.000

Substitusi:
6(240.000)x + 5y = 1.815.000
1.440.000 + 5y = 1.815.000
5y = 1.815.000 - 1.440.000
5y = 375.000
y = 375.000/5
y = 75.000
4. Hasil Akhir

Harga smart waste: Rp240.000

Harga kipas angin smart: Rp75.000

5. Refleksi

Dari kegiatan ini, saya memahami cara menyelesaikan permasalahan menggunakan SPLDV. Kesulitan yang dihadapi adalah menentukan langkah eliminasi dan substitusi dengan benar. Saya berkontribusi dalam perhitungan, memberikan ide, berdiskusi, dan bekerja sama dengan kelompok.

Puri Ayu Agustina

X PPLG 4 / 32

Foto Produk Pengerjaan Puri Ayu Agustina

1. Menentukan Variabel

x = harga satuan 1 pot bunga dari keyboard bekas.

y = harga satuan 1 lumiclock CD pelangi besar.

2. Membuat Model Matematika

Paket 1: 5x + 2y = 185.000
Paket 2: 2x + 5y = 200.000

3. Penyelesaian

5x + 2y = 185.000 | ×5
2x + 5y = 200.000 | ×2

25x + 10y = 925.000
4x + 10y = 400.000
21x = 525.000
x = 525.000/21
x = 25.000

_________________-
Substitusi:
5x + 2y = 185.000 5x(25.000) + 2y = 185.000
2y = 185.000 - 125.000
2y = 60.000
y = 60.000/2
y = 30.000
4. Hasil Akhir

Harga pot bunga dari keyboard bekas: Rp25.000

Harga lumiclock CD pelangi besar: Rp75.000

5. Refleksi

Melalui tugas ini, saya memahami bahwa SPLDV dapat digunakan untuk menentukan harga dua jenis produk. Kesulitan yang dihadapi adalah proses eliminasi dan substitusi. Saya ikut membantu perhitungan, memberikan ide, dan berdiskusi dalam menyelesaikan tugas kelompok.
